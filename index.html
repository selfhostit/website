Install in one line

On a Raspberry Pi, a Linux server or a NAS with SSH. It installs Docker if needed, asks which apps you want and starts them. Run it again to update.

curl -fsSL https://raw.githubusercontent.com/selfhostit/docs/main/install.sh | sh
  1. Run the installer and pick your apps.
  2. Give them an HTTPS address with Tailscale or your own domain.
  3. Open them on your phone and add them to the home screen.
